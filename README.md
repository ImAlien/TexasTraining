# Preflop Lab · 翻前训练室

一个无需安装第三方依赖的中文德州扑克翻前范围训练应用。支持桌面和手机浏览器。

## 本地启动

Windows 可双击项目上级目录的 `start-local.cmd`，停止当前项目的旧服务后重新启动，并自动打开浏览器。运行期间请保持窗口打开；服务退出或启动失败后，窗口会停留显示结果，不会闪退。若端口由其他程序占用，会显示提示，不会停止其他程序。命令行可运行 `node scripts/restart-local.mjs --open` 执行同样的重启流程。

需要 Node.js 22 或更新版本。在此目录运行：

```sh
node scripts/serve.mjs
```

打开 http://127.0.0.1:5173 。也可以使用 `npm run dev`；Windows PowerShell 如遇系统的 npm.ps1 限制，请使用 `npm.cmd run dev`。

```sh
node --test tests/*.test.mjs
node scripts/build.mjs
```

构建生成 `dist/`，可以部署到任意静态网站服务。源码使用原生 ES modules，不依赖打包器。通过 HTTP 服务打开，请勿直接双击 HTML。

## 已接入的公开推弃数据

独立模式：单挑 4 / 6 / 8 / 10 / 12 / 15 / 20BB，SB 全下 / 弃牌，BB 跟全下 / 弃牌。
来源为 [HoldemMath](https://holdemmath.com/) 的 CC BY 4.0 公开近似 Nash 图表。
无前注、无抽水、chipEV；来源声明最佳响应偏差 ε ≤ 0.05BB，未独立复算。
它只发布离散手牌列表，没有完整混合频率。界面以“图表行动”训练，不把列表映射的 0/100 宣称为原始求解频率。

**这不是 100BB 完整 GTO。** 单挑、6 人、9 人 100BB 仍没有合格公开数据接入。
旧教学模式和历史错题保留并明确标注非 GTO。新浏览器默认进入单挑 10BB 推弃。
详情、固定数据版本、原始文件哈希和改动声明见 [DATA-SOURCES.md](DATA-SOURCES.md)。

## 功能

- 2 人、6 人、9 人桌，合法翻前位置；单挑 SB 同时为 BTN。
- 66 个原教学场景，另有 14 个公开单挑推弃场景；支持随机位置与混合训练。
- 169 类起手牌，按实际 1,326 个组合加权抽题；同花、非同花和对子发牌不重复。
- 弃牌、跟注 / 小盲 limp、加注，展示筹码、底池与行动历史。
- 答题后显示完整 13×13 范围矩阵、单手牌行动频率和组合加权范围占比。
- 提示、直接揭晓、范围库浏览。已查看提示或范围的当前题不计分；跳过不计分。
- 混合策略中的所有非零频率行动均接受。不以随机抽样结果误判其他合法混合行动。
- 错题按范围库 + 场景 + 手牌归档去重；重复错误累计。专项复习连续 3 次独立答对后标记已掌握，出错重新归档。
- 训练统计、错题、范围库和偏好保存在当前浏览器的 localStorage；可导出 JSON 记录备份。不跨设备同步。备份目前用于归档，不提供界面恢复入口。
- 自定义范围 JSON 导入 / 模板导出，严格验证场景、完整手牌覆盖、频率、参数和下注尺度。
- 键盘 F / C / R 作答，空格换题。使用表单、按钮或弹窗时不抢占键盘输入。

## 100BB 教学库的准确性与限制

**以下仅描述保留的 100BB 教学库。** 它自行编写，不是求解器输出，不声称是精确 GTO。频率包含人为简化与边界混合。范围验证测试只能证明导入和游戏规则一致，不能证明策略达到纳什均衡。公开短码推弃模式的独立参数见上文与 DATA-SOURCES.md。

- 100BB，有效筹码相同，无前注；未建模抽水。
- 常规开池至 2.5BB；多人桌 SB 至 3BB；单挑 SB 至 2.5BB。
- 面对开池有位置 3-bet 至 8BB，无位置至 10BB；BB 对 SB 至 8BB。
- 多人桌内置 RFI 使用 raise/fold 简化树，单挑 SB 包含 limp。
- 只训练率先入池或面对一次加注，前面其他玩家均弃牌。暂不包含面对 3-bet、挤压、多人跟注、短码推弃、锦标赛 ICM 或翻后。
- “符合范围率”只检验选择的行动频率是否大于 0，不评价长期混频是否正确，也不是 EV 损失指标。
- 精确 GTO 数据需来自用户有权使用的求解器或授权范围库，且需要与上述参数一致。当前应用不会自动调用或模拟求解器。

## 自定义范围

公开推弃范围也可导出再导入：仍使用 `preflop-lab-v1`，但 `sizing` 为 `hu-pushfold-v1`，`stack` 为所选深度，`representation` 为 `binary-chart`。仅支持单挑、2–20BB、无前注的推弃树；导入后的来源仍标记为用户提供、未独立验证。


在“范围库”或“范围来源与假设”中导出完整 JSON 模板。可只保留需要的场景，然后替换手牌频率。

```json
{
  "format": "preflop-lab-v1",
  "name": "我的 100BB 范围",
  "source": "填写求解工具、参数和授权来源",
  "description": "策略说明",
  "stack": 100,
  "ante": 0,
  "rake": "填写求解时的抽水设置",
  "sizing": "standard-v1",
  "spots": [
    {
      "table": 6,
      "scene": "rfi",
      "hero": "UTG",
      "opener": null,
      "ranges": { "AA": { "fold": 0, "call": 0, "raise": 100 } }
    }
  ]
}
```

上面仅示意结构，实际每个场景必须包含完整 169 类手牌。频率为 0–100 数字，三项之和必须为 100。桌型为 `2`、`6` 或 `9`；场景为 `rfi` 或 `defend`。RFI 的 `opener` 为 `null`，vs Open 的 opener 必须在 hero 之前。非小盲的 RFI 不接受 limp。最多 100 个场景，文件最大 2MB，最多 8 个自定义库。导入不会验证求解器来源或均衡精度。

## 项目结构

- `src/engine.js`：位置、范围、组合、发牌、判分、错题更新及导入校验。
- `src/storage.js`：持久化与损坏记录保护。
- `src/app.js`：界面与交互。
- `src/styles.css`：响应式牌桌和范围矩阵。
- `tests/engine.test.mjs`：全部场景、发牌、混合判分、盲注核算、复习、导入及持久化测试。
- `scripts/serve.mjs`：仅监听 127.0.0.1 的开发服务器。
- `scripts/build.mjs`：静态构建。

字体加载使用 Google Fonts；不可用时自动回退至系统字体。游戏与本地保存无需后端服务。

## BB vs SB limp 专项

顶部「Limp 专项」支持单挑 10BB、20BB 的原图对照训练：选择过牌、两档隔离加注或全下后，直接显示对应的本地 BB 原图，自评「符合原图」或「需要复习」。支持 SB / BB 图切换、放大、保存图片，以及 52 张原图的本地图册。查看图片无需联网。错题自动收录，在「错题本 → Limp 专项错题」复习，连续三次通过后标记已掌握。

公开文章只有范围图片，内置模式没有完整频率，不能自动判分。另支持导入完整 169 手牌的专用 JSON 频率，启用自动判分与范围矩阵。6 / 9 人桌尚无内置 limp 答案；MTT 文章仅作参考链接。来源、适用参数与导入格式见 [LIMP-DATA.md](LIMP-DATA.md)。
